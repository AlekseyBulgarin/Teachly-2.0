name: teachly-ui
description: Design and polish the Teachly Ecosystem Showcase using the Teachly premium dark B2B visual system.
---

Use this skill for Showcase layout, typography, navigation, cards, responsive design and visual polish.

Audience:
- educational business owners
- online school directors
- non-technical decision makers

Principles:
- premium dark B2B design
- strong Cyrillic readability
- comfortable typography
- generous whitespace
- fewer, larger cards
- clear visual hierarchy
- restrained emerald accent
- subtle borders

Avoid:
- tiny primary text
- generic AI-dashboard styling
- excessive gradients or glow
- dense metric grids
- excessive badges
- unnecessary animation

Desktop:
- sidebar must never overlap content
- maintain readable content width
- no horizontal overflow

Mobile:
- use an accessible drawer
- clear single-column layout
- no clipped content

Reuse existing project components first.
Use shadcn MCP when an existing accessible primitive is appropriate.

Prefer:
reuse > integrate > extend > build from scratch.
