# MVP Definition

## Goal

Prove that a teacher can run a useful preparation loop without leaving Teachly. MVP is not a complete examination platform and does not require every initial subject to have full content on day one.

## MVP Includes

- teacher registration and personal workspace;
- student records and minimal groups;
- subject/course/topic structure as configurable content;
- imported raw content with provenance;
- normalization and validation for a deliberately small task-type set;
- canonical published task versions;
- teacher-created training or homework;
- student task attempts;
- deterministic evaluation and feedback;
- generic assessment/slice with selected tasks;
- basic topic/skill progress;
- teacher result and mistake views;
- PostgreSQL-backed learning events;
- authorization, audit foundation, and organization-ready ownership fields.

The exact initial content rollout is unresolved. Architecture must support all listed subjects, while launch content may use a smaller validated subset.

## Phase 2

- richer organization administration;
- expanded homework and notification workflows;
- error review and weakness-based practice;
- code execution if security and product value are confirmed;
- parent monitoring UI;
- AI hints, explanations, teacher feedback assistance, and bounded recommendations;
- richer analytics and progress dynamics;
- additional task types and educational materials;
- subscription enforcement.

## Phase 3

- specification-driven exam simulations;
- advanced content moderation workflows;
- organization programs and organization-owned content;
- multi-provider AI routing;
- integration pilot with external education products;
- public API hardening and webhooks.

## Future

- formal external examination integrations;
- mobile applications and Telegram Mini App;
- embeddable components and SDKs;
- advanced adaptive learning;
- marketplace, video, calls, and whiteboard capabilities;
- autonomous AI agents and ML infrastructure.

## Deliberate Exclusions

Payments, production code execution, public integrations, a full parent dashboard, complex adaptive algorithms, and broad multi-subject content authoring must not block the first vertical loop.
