# Functional Map

## Scope Labels

- **MVP:** required to demonstrate the teacher-first learning loop.
- **Phase 2:** valuable after the loop is proven.
- **Phase 3:** platform expansion requiring more product evidence.
- **Future:** intentionally deferred capabilities.

## Identity and Workspaces

- Registration, sign-in, account recovery, and profile: **MVP**
- Teacher workspace and personal students: **MVP**
- Organization memberships and invitations: **MVP minimal / Phase 2 expanded**
- Guardian relationships and consent: **Architectural support / Phase 2 UI**
- Platform administration and moderation: **Phase 2**

## Teacher Operations

- Student management: **MVP**
- Groups/classes: **MVP minimal**
- Training creation and assignment: **MVP**
- Homework lifecycle: **MVP minimal**
- Assessment/slice creation: **MVP minimal**
- Feedback and grading: **MVP deterministic results / Phase 2 richer feedback**
- Teacher analytics: **MVP core / Phase 2 advanced**
- Organization programs and content ownership: **Phase 2**

## Student Learning

- Subject/course/topic navigation: **MVP**
- Assigned training: **MVP**
- Task solving and answer submission: **MVP**
- Deterministic evaluation and feedback: **MVP**
- Learning sessions and history: **MVP minimal**
- Skill/topic progress: **MVP basic**
- Error review and weakness-based practice: **Phase 2**
- Personal learning paths: **Phase 2**
- Advanced adaptive learning: **Future**

## Content and Task Engine

- Raw import batches and provenance: **MVP content foundation**
- Normalization and validation: **MVP for supported task types**
- Canonical task and immutable published versions: **MVP**
- Topic/skill mapping: **MVP basic**
- Media and educational materials: **Phase 2**
- Code execution tasks: **Phase 2, subject to sandbox decision**
- Generated variants and localization: **Phase 3**

## Assessment

- Generic assessment definition: **MVP**
- Teacher-created slices: **MVP**
- Assessment attempts and task attempts: **MVP**
- Timing and configurable rules: **MVP minimal**
- Exam simulations and specification-driven scoring: **Phase 2**
- Formal external examination workflows: **Future**

## AI

- AI boundary and usage controls: **MVP architecture**
- Student hints/explanations: **Phase 2**
- Teacher feedback and activity assistance: **Phase 2**
- Error analysis and recommendations: **Phase 2**
- Multi-provider routing: **Phase 2/3**
- Autonomous agents: **Not planned**

## Platform and Analytics

- Authorization, organization scope, and audit foundation: **MVP**
- Notifications: **MVP minimal / Phase 2**
- PostgreSQL-backed learning events: **MVP**
- Product analytics and advanced aggregation: **Phase 2**
- Billing and subscriptions: **Phase 2/3**
- Public integrations, webhooks, SDKs, and embeddables: **Future**
- Mobile and Telegram Mini App: **Future**
